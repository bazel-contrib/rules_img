rules_img pre-release registry

A Bazel registry serving one rules_img version per commit to the main branch, so a change can be tried out before it is released. Sources: https://github.com/bazel-contrib/rules_img.

Using it

Add the registry, keeping the Bazel Central Registry as the fallback for everything else:

common --registry=https://bazel-contrib.github.io/rules_img --registry=https://bcr.bazel.build

Then depend on a version from the table below:

bazel_dep(name = "rules_img", version = "0.3.20-20260811-7e77751")

Versions

0.3.20-20260811-39082ed 2026-08-11 39082ed

What you get

Each version is the module source as of one commit, carrying a prebuilt lockfile that fetches the img tool from ghcr.io/bazel-contrib/rules_img/img as an OCI blob, so no tool is built from source. Versions are pre-releases of the next patch version: they resolve above the last release and below the next one. Nothing here is a supported release -- a version may be rewritten by a re-run of the build that produced it, and no version is ever removed.
